The usual search path

InputScreen: tap Search → App: open word route → ViewModel: Loading → Use case: clean word → Repository: Room cache or Ktor APIs → ViewModel: Success/Error → Compose: redraw Result

Saving a word also changes Room’s history Flow. That updates ViewModel.searchHistory, then HistoryScreen. A favorite is a database update; a slang default is a DataStore update.

Learn the shared app files first. Platform setup, tests and the extra browser worker appear later. The modules teach the concepts; some real platform/library setup is additional to their simplified examples. Generated code, Gradle wrapper scripts, binary assets and Xcode project internals are not annotated as handwritten app logic.
